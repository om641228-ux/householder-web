# Настройка прямой загрузки больших файлов (v70)

Файлы больше 1 ГБ (до 5 ГБ) грузятся напрямую в Cloudflare R2 кусками по 32 МБ,
минуя сервер. Настройка один раз, ~15 минут.

## 1. Cloudflare R2 (бесплатно: 10 ГБ, трафик бесплатный)

1. Зарегистрируйся: https://dash.cloudflare.com → R2 → **Create bucket** → имя: `householder-docs`.
2. Bucket → **Settings** → **Public access** → включи r2.dev URL → скопируй ссылку вида `https://pub-xxxx.r2.dev`.
3. Bucket → **Settings** → **CORS** → добавь политику:
```json
[{"AllowedOrigins": ["https://householder-web-production.up.railway.app"], "AllowedMethods": ["PUT", "GET", "HEAD"], "AllowedHeaders": ["*"], "ExposeHeaders": ["ETag"], "MaxAgeSeconds": 3600}]
```
4. R2 → **Manage R2 API Tokens** → **Create API token** (права: Object Read & Write, только этот bucket) → скопируй **Access Key ID** и **Secret Access Key**. **Account ID** виден в URL кабинета.

## 2. Railway → householder-api → Variables

```
R2_ACCOUNT_ID = <Account ID>
R2_ACCESS_KEY_ID = <Access Key ID>
R2_SECRET_ACCESS_KEY = <Secret Access Key>
R2_BUCKET = householder-docs
R2_PUBLIC_URL = https://pub-xxxx.r2.dev
```

## 3. package.json сервиса householder-api

В `dependencies` добавить (Railway установит сам при деплое):
```json
"@aws-sdk/client-s3": "^3.0.0",
"@aws-sdk/s3-request-presigner": "^3.0.0"
```

## 4. Деплой

- householder-api ← index.js (md5 `0a5dde2668295b1809536b517d842f6c`)
  - проверка: GET /api/health → `build: "v70-2026-08-24"`
- householder-web ← App.js (md5 `a5093654ff33371095cc663c65eaa8ae`)
  - метка внизу страницы: **· v70 ·**

## Проверка

Загрузи файл >1 ГБ в «Документы». В окне прогресса должно быть:
«☁️ имя · часть N/M». Если облако не настроено — всплывёт подсказка, чего не хватает.

## Как это работает потом

- ≤1 ГБ — как раньше, через сервер.
- >1 ГБ — частями прямо в облако; обрыв/«Остановить» ничего не теряет: повторный
  выбор того же файла продолжит загрузку с места обрыва (докачка).
- Файл доступен по публичной, но не угадываемой ссылке (как сейчас в Supabase).
